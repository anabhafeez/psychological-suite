#  Psychological Suite

A comprehensive clinical web app built with Streamlit for psychological screening and reporting.

## Tools Included

- **Progress Tracker** — Track symptom scores across sessions & visualize trends
- **Clinical Assessment** — Run GAD-7, PHQ-9, PSS-10, PCL-5, and Sleep (ISI) screenings
- **Session Report** — Generate & download full clinical session reports

## Run Locally

```bash
pip install -r requirements.txt
streamlit run psychological_suite.py
```

## Requirements
- streamlit
- plotly

## Disclaimer
This tool is for screening purposes only and is **not** a substitute for clinical diagnosis.
